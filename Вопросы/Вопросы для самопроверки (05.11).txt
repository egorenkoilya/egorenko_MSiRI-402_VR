1) Коллайдер — компонент Unity, который определяет форму объекта для столкновений. Коллизия — само столкновение двух объектов.

2) While сначала проверяет условие, затем выполняет код. Do while сначала выполняет код, а потом проверяет условие. Поэтому do while выполняется минимум один раз.

3) Основные методы Web-запросов: GET — получение данных, POST — отправка данных, PUT — полное обновление, PATCH — частичное обновление, DELETE — удаление данных.

4) OnCollision используется для обработки физических столкновений объектов. OnTrigger используется для определения входа объекта в специальную зону, например для подбора предметов или обнаружения игрока.

5) Интерфейс Input нужен для получения действий пользователя: нажатия клавиш, движения мыши, нажатия кнопок и управления персонажем.
