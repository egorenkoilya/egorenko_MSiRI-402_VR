1) Отличие коллайдера от коллизии.

Коллайдер (Collider) — компонент Unity, который определяет форму объекта для столкновений. Коллизия (Collision) — само событие столкновения двух объектов.

2) Отличие while от do while.

While сначала проверяет условие, затем выполняет код. Do while сначала выполняет код, а потом проверяет условие. Поэтому do while выполняется минимум один раз.

3) Методы Web-запросов.

GET — получение данных. POST — отправка данных. PUT — полное обновление данных. PATCH — частичное обновление данных. DELETE — удаление данных.

4) Когда используются OnCollision и OnTrigger.

OnCollision используется для обработки физических столкновений объектов. OnTrigger используется, когда объект входит в специальную зону или выходит из неё без физического столкновения.

5) Для чего нужен интерфейс Input.

Input — класс Unity, который позволяет получать действия пользователя: нажатия клавиш, движения мыши и нажатия кнопок. Используется для управления игровыми объектами.
